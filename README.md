# ICS Catalog Items

ServiceNow Fluent SDK application for ICS catalog items.

## Development workflow

1. Create or switch to a feature branch.
2. Make the required code changes.
3. Validate and build the application.
4. Commit changes to the feature branch.
5. Push the feature branch to GitHub.
6. Create a Pull Request into `main`.
7. Review and approve the Pull Request.
8. Merge the Pull Request into `main`.

## Workflow summary

Make changes → Validate and build → Commit to feature branch → Push to GitHub → Create Pull Request → Review → Merge into main

## Branch naming

Examples:

- `feature/ics-form-generator`
- `feature/ics-cloud-request`
- `fix/request-laptop-validation`
- `docs/catalog-item-guidance`

Do not commit changes directly to `main`.
